Recommended loop

  1. Record the context: target board, branch, machine configuration, image, and reproduction conditions.
  2. Reduce it to a minimal reproduction with the necessary commands, configuration, and logs.
  3. Verify and preserve the fix in a layer, recipe, or document, then commit it to Git.
  4. Publish the knowledge with verification results, risks, and official references.
Capture → Minimal reproduction → Verification → Git commit → Site publication

Record format

  • Context: goal, platform, version, and constraints.
  • Operation: commands or configuration that can be reused.
  • Verification: logs, tests, or inspectable artifacts.
  • Risk: version differences, destructive actions, and rollback.
  • References: official documentation, commits, and related issues.
