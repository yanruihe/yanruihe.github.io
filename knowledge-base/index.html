整合方式

专题记录什么何时查阅
Git变更边界、提交历史、协作与恢复开始修改、准备评审、需要回滚时
Yocto层、配方、机器、镜像与构建日志新增软件、适配硬件、排查构建时
项目知识平台版本、验证命令、已知限制和产物交接、复现问题、发布版本时

推荐闭环

  1. 记录问题背景：目标板、分支、机器配置、镜像和复现条件。
  2. 提炼最小复现：保留必要的命令、配置和关键日志。
  3. 验证并固化：把可复用的修改放进层、配方或文档，并在 Git 中提交。
  4. 发布知识：补充验证结果、风险和官方参考链接，再更新静态站点。
采集问题 → 最小复现 → 验证结果 → Git 提交 → 站点发布

记录规范

  • 背景：目标、平台、版本和约束。
  • 操作：可以复制执行的命令或配置。
  • 验证：日志、测试命令或可检查的产物。
  • 风险：版本差异、破坏性操作和回滚方式。
  • 参考：官方文档、提交记录和关联问题。
